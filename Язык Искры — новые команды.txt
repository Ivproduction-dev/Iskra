ИСКРА — ЯЗЫК: НОВЫЕ КОМАНДЫ (ФИНАЛЬНЫЙ СЛОЙ)
Решения обсуждения от 19.10.2026. Все пункты согласованы.
Старый файл «Планы Искра.txt» не считать актуальным.
Этот документ — спецификация для реализации.

Формат команд (сложившийся стиль):
- Ключевая цепочка с точками, затем данные до конца строки.
- Точки внутри имён сцен/объектов/файлов разрешены.
- Регистр букв неважен.

======================================================================
0. ГЛОБАЛЬНЫЕ ПЕРЕМЕННЫЕ (РЕФАКТОРИНГ) — ВЛИЯЕТ НА ВСЁ
======================================================================

[РЕШЕНО] Переменные — ОДИН ОБЩИЙ БАНК на всю игру:
- «Задать счёт = 1» в любом объекте и в любой сцене — переменная «счёт»
  одна и та же везде;
- при переходе между сценами переменные сохраняются;
- при новом запуске игры очищаются: старт с нуля;
- снапшоты сцен (см. раздел «Сцены») хранят их.
[РЕШЕНО] Из этого следует: «чужие переменные» отдельным синтаксисом
не нужны — любое имя читается и меняется из любого скрипта.
[РЕШЕНО] Имя переменной не может начинаться на «Свойство.» (префикс
зарезервирован за свойствами объекта) и не может заканчиваться точкой.

======================================================================
1. КЛАВИАТУРА
======================================================================

[РЕШЕНО] Событие нажатия клавиши — с точкой после «При»:
    При. нажатии клавиши.КЛАВИША
        ... тело ...
    Конец
- глобальное событие, не связано с объектом сцены;
- срабатывает один раз на физическое нажатие; авто-повтор ОС
  новое событие не вызывает.

[РЕШЕНО] Словарь клавиш:
- «право», «лево», «верх», «вниз» (короткие, без слова «стрелка»);
- «пробел», «ввод» (Enter), «отмена» (Escape), «забой» (Backspace);
- буквы и цифры — самим символом: «клавиши.А», «клавиши.5»
  (кириллица и латиница).

[РЕШЕНО] Чтение состояния для условий:
    Свойство.клавиша.КЛАВИША
    Пример: Если Свойство.клавиша.пробел = истина то
- истина, пока зажата; ложь, когда отпущена.

[РЕШЕНО] «При. нажатии» (клик объектом) и «При. нажатии клавиши.X»
различаются хвостом: у клавиатуры после «нажатии» идёт «клавиши.ИМЯ»,
у клика строка на этом заканчивается — конфликта с переменными нет.

[РЕШЕНО] Старые события («При. запуске», «При. нажатии», «При. отпускании»,
«При. наведении», «Когда … то») записываются как раньше — не меняются;
«Конец» у них допустим, но не обязателен.

[НА ПОЗЖЕ] Событие отпускания клавиши («При. отпускании клавиши.X»).
======================================================================
2. ТАЙМЕРЫ
======================================================================

[РЕШЕНО] Таймер по секундам:
    Каждые.N.секунды
        ... тело ...
    Конец
- ловит все формы слова: секунда/секунды/секунду/секунд;
- N — только целое число (дроби не поддерживаются);
- первое срабатывание — через N секунд, не мгновенно.

[РЕШЕНО] Событие каждого кадра:
    Каждый кадр
        ... тело ...
    Конец
- тело выполняется один раз на отрисованный кадр (~60 раз в секунду);
- если тело не успело до следующего кадра — кадр пропускается,
  ускорения и параллельных экземпляров нет;
- сохраняется независимо от «Вечно»: темп «Вечно» не ограничен,
  темп «Каждый кадр» привязан к отрисовке.

[РЕШЕНО] Оба блока вечные по природе: «Конец» обязателен,
«Прервать» внутри не работает.
======================================================================
3. ВИДИМОСТЬ
======================================================================

[РЕШЕНО] Без объекта — действие на свой объект (где написан скрипт):
    Спрятать          Скрыть          Показать
«Скрыть» — синоним «Спрятать».

[РЕШЕНО] С точкой — действие на чужой объект:
    Спрятать.монета          Скрыть.монета          Показать.монета
Точка обязательна, чтобы интерпретатор не путал имя объекта
с переменной.

[РЕШЕНО] Поведение: спрятанный объект не отображается, не участвует
в касаниях, «При нажатии»/«При наведении» на нём не срабатывают,
но его скрипты продолжают работать.
======================================================================
4. ПОЗИЦИЯ И ДВИЖЕНИЕ
======================================================================

[РЕШЕНО] Запись координат — только через префикс «Свойство.»:
    Задать Свойство.х = ЧИСЛО     # абсолютное значение X (0 — центр)
    Изменить Свойство.х ЧИСЛО     # сдвиг; плюс — вправо, минус — влево
    Задать Свойство.у = ЧИСЛО     # абсолютное значение Y
    Изменить Свойство.у ЧИСЛО     # сдвиг; плюс — вниз, минус — вверх
- «=» только у «Задать» — как у переменных: «Задать счёт = 5»,
  «Изменить счёт 5»;
- «Задать х. 5» и «Изменить х. 5» в язык не входят;
- «Изменить счёт 1» — переменная, «Изменить Свойство.х 5» — свойство:
  имена переменных с префиксом «Свойство.» запрещены.

[РЕШЕНО] Сдвиг по обеим осям:
    Подвинуть. DX DY
    Пример: Подвинуть. 10 -5

[РЕШЕНО] «Поместить X Y» остаётся как было: абсолютное позиционирование.

[РЕШЕНО] Чтение позиции — уже существующие «Свойство.х» и «Свойство.у»
(логические пиксели сцены, 0 0 — центр).
======================================================================
5. СТОЛКНОВЕНИЯ
======================================================================

[РЕШЕНО] Свойство касания:
    Свойство.коснулся.ИМЯ ОБЪЕКТА
    Пример: Когда Свойство.коснулся.монстр то
- истина, пока пересекаются прямоугольники (границы спрайтов);
- состояние обновляется автоматически каждый кадр;
- только объекты той же сцены; Фон и объекты без спрайтов
  не участвуют (нет прямоугольника).
======================================================================
6. СЦЕНЫ ВО ВРЕМЯ ЗАПУСКА
======================================================================

[РЕШЕНО] Запуск сцены (свежий старт):
    Запустить.сцену.ИМЯ СЦЕНЫ
    Пример: Запустить.сцену.главное меню
- выполняется МГНОВЕННО в строке, где встречена;
- ПРИНУДИТЕЛЬНО прерывает все скрипты всех объектов текущей сцены:
  «Вечно», «Пока», «Ждать», «Воспроизвести звук ждать» — всё обрывается;
- строки после «Запустить.сцену. ...» в этом скрипте НЕ выполняются;
- глобальные переменные сохраняются (см. раздел 0).

[РЕШЕНО] Продолжение сцены со снапшота:
    Продолжить.сцену.ИМЯ СЦЕНЫ
- при каждом уходе со сцены сохраняется снапшот (кодовый, в темп-файл):
  что где стояло, где скрипты остановились, состояние объектов;
- «Продолжить.сцену.X» восстанавливает снапшот и продолжает с места
  останова.

[РЕШЕНО] Состав снапшота — сохраняется ВСЁ состояние сцены:
- позиции объектов, размер, прозрачность, яркость;
- видимость (спрятано/показано);
- глобальные переменные;
- номер строки, где остановился каждый скрипт;
- звуки: позиция воспроизведения — звук продолжается с того же места
  (записываем, когда закончился/остановился);
- таймеры «Каждые.N.секунды» — отсчёт начинается заново.
======================================================================
7. ОРИЕНТАЦИЯ ВО ВРЕМЯ ЗАПУСКА
======================================================================

[РЕШЕНО] Переключение на противоположную:
    Сменить.ориентацию
- горизонтальная ↔ вертикальная.

[РЕШЕНО] Явное задание:
    Сменить.ориентацию.горизонтальная
    Сменить.ориентацию.вертикальная

[РЕШЕНО] Скрипты НЕ прерывает, объекты продолжают работать;
- действует на все сцены до конца запуска, переходами сцен
  не сбрасывается; при новом запуске игры — ориентация проекта;
- объекты сами не перестраивают раскладку.
======================================================================
8. ЗВУК
======================================================================

[РЕШЕНО] Зацикливание:
    Зациклить звук.ФАЙЛ
    Пример: Зациклить звук.тема.mp3
- играет по кругу.

[РЕШЕНО] Остановка:
    Остановить звук.ФАЙЛ

[РЕШЕНО] Громкость:
    Задать громкость.ЧИСЛО                # глобальная: все звуки игры
    Задать громкость.ФАЙЛ ЧИСЛО           # конкретный звук
    ЧИСЛО — 0..100
======================================================================
9. АНИМАЦИЯ ИЗОБРАЖЕНИЙ
======================================================================

[РЕШЕНО] Автоматическое листание образов объекта:
    Проиграть изображение.SPEED                 # свой объект
    Проиграть изображение.ОБЪЕКТ SPEED          # чужой объект
    Остановить изображение.                     # свой объект
    Пример: Проиграть изображение.монстр 8
- SPEED — кадров в секунду; кадры идут по кругу;
- остановка возвращает управление кадрами существующим
  «Изменить изображение. перед/назад».
======================================================================
10. ВВОД ТЕКСТА ИГРОКОМ
======================================================================

[РЕШЕНО] Синтаксис:
    Спросить.ВОПРОС ИМЯ
    Пример: Спросить. "Как тебя зовут?" имя
- на сцене появляется поле ввода с вопросом;
- введенная строка сохраняется в глобальную переменную ИМЯ;
- «спросить» без точки (консольная форма «Спросить ... . Да . Нет
  сохранить в X») остаётся как есть.
======================================================================
11. ПРАВИЛО РАЗБОРА ТОЧЕК
======================================================================

[РЕШЕНО] В командной строке: сначала ключевая цепочка с точками
(«Запустить.сцену.», «Каждые.», «Задать громкость.», «Задать х.»),
всё после неё — данные до конца строки:
- «Запустить.сцену.главное меню» → имя = всё после «.сцену.»;
- «Продолжить.сцену.главное.меню» — тоже валидно (точки в имени);
- «Задать громкость.тема.mp3 40» → число последнее, остальное — файл.
Именно поэтому нет конфликтов: заголовок команды отделяет её
от данных раньше, чем интерпретатор встретит другие точки.
======================================================================
12. НА ПОЗЖЕ И УБРАННОЕ
======================================================================

- «Написать. …» текст в сцене и «Стереть.» — синтаксис обсудим позже,
  текущий вариант не принят.
- «Сохранить.» / «Загрузить.» — потребности нет; можно сделать,
  в активный план не входит.
- «При. отпускании клавиши.X» — позже.
======================================================================
