# Искра

Интерпретатор написан на C++. Исходники Искры используют расширение `.isk` и сохраняются в UTF-8 (с BOM или без него). Сейчас язык умеет хранить целые числа и тексты в переменных, менять числа и печатать значения.

```text
Задать счёт = 5
Изменить счёт 1
Печать счёт
Изменить счёт -1
Печать счёт
Задать привет = "хеллоу ворлд"
Печать привет
```

`Задать` и `Присвоить` — синонимы: команда создаёт переменную или присваивает ей новое значение. `Изменить имя число` прибавляет число к переменной; отрицательное число уменьшает значение. `Печать имя` выводит значение переменной. Регистр команд не важен, имена переменных чувствительны к регистру.

Переменные и команды разделяются пробелами. Значения — целые числа или тексты в двойных кавычках (пробелы внутри кавычек разрешены, `\"` и `\\` — экранирование). Каждая команда пишется на отдельной строке.

Оператор `..` склеивает тексты и значения переменных; числа при склеивании превращаются в текст. Пробелы вокруг оператора необязательны.

```text
Задать имя = "Искра"
Задать приветствие = "Привет, "..имя.."!"
Печать приветствие
Печать "Счёт: "..5
```

Комментарии начинаются с `#` или `//` и идут до конца строки. Решётка и слэши внутри кавычек — часть текста, а не комментарий.

События: скрипты стартуют по событиям. Блок `При запуск ... Конец` выполняется при запуске (синоним — `При запуск сцены`). Других событий пока нет — такие блоки пропускаются. Событий в одном скрипте сколько угодно, вкладывать событие в событие нельзя. Код вне событий выполняется при запуске как неявное событие.

Вопросы: `Спросить вопрос? . Да . Нет сохранить в имя` показывает вопрос и две кнопки, в переменную сохраняется `да` (первая кнопка) или `нет` (вторая). Части разделяются точкой с пробелами с обеих сторон. В консоли отвечает вводом `1`, `2` или текстом кнопки; в приложении будет окно.

Условия: `Если`, `Есле` и `Если` — одно и то же. После условия обязательно слово `Тогда`, блок закрывается словом `Конец` или `КонецЕсли`, посередине может быть `Иначе`. Веток `ИначеЕсли ... Тогда` может быть сколько угодно — выполняется первая подошедшая. Вложенные `Если` разрешены.

```text
Если счёт > 3 Тогда
    Печать счёт
ИначеЕсли счёт = 0 Тогда
    Печать ответ
Иначе
    Печать ответ
КонецЕсли
```

Сравнивать можно числа (`=`, `!=`, `>`, `<`, `>=`, `<=`) и тексты (только `=` и `!=`). Имена переменных могут совпадать с командами: `Задать если = 7` работает.

Циклы: `Пока условие Тогда ... Конец` повторяет блок, пока условие верно. Вечные циклы разрешены — останавливаются прерыванием. Вложенность любая.

## Сборка и запуск

Нужен компилятор C++17 или новее.

```sh
g++ -std=c++17 -O2 -o iskra main.cpp
./iskra example.isk
```

В Windows откройте **Developer Command Prompt for VS 2026 Insiders** и выполните:

```powershell
cl /std:c++17 /O2 /EHsc /utf-8 main.cpp /Fe:iskra-runtime.exe
chcp 65001
iskra example.isk
```

## Unit-тесты

Тесты логики интерпретатора находятся в `tests/interpreter_tests.cpp`. В Developer Command Prompt for Visual Studio из папки проекта запусти:

```powershell
cl /std:c++17 /EHsc /utf-8 tests\interpreter_tests.cpp /Fe:iskra-tests.exe
.\iskra-tests.exe
```
