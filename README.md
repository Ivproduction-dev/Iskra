# Искра

Свой язык программирования на русском. Интерпретатор написан на C++ (`main.cpp`), оболочка и рантайм — на C# (папка `IskraStudio`). Исходники Искры используют расширение `.isk` и сохраняются в UTF-8 (с BOM или без него). Регистр команд не важен, имена переменных чувствительны к регистру.

## Переменные

```text
Задать счёт = 5
Изменить счёт 1
Печать счёт
Изменить счёт -1
Печать счёт
Задать привет = "хеллоу ворлд"
Печать привет
```

`Задать` и `Присвоить` — синонимы: команда создаёт переменную или присваивает ей новое значение. `Изменить имя число` прибавляет число к переменной; отрицательное число уменьшает значение. `Печать имя` выводит значение переменной.

Переменные — один общий банк на всю игру: `Задать счёт = 1` в любом объекте и в любой сцене создаёт одну и ту же переменную `счёт`. При переходе между сценами переменные сохраняются, при новом запуске игры очищаются. Имя переменной не может начинаться на `Свойство.` (префикс зарезервирован за свойствами объекта) и не может заканчиваться точкой.

Переменные и команды разделяются пробелами. Значения — целые числа или тексты в двойных кавычках (пробелы внутри кавычек разрешены, `\"` и `\\` — экранирование). Каждая команда пишется на отдельной строке.

Оператор `..` склеивает тексты и значения переменных; числа при склеивании превращаются в текст. Пробелы вокруг оператора необязательны.

```text
Задать имя = "Искра"
Задать приветствие = "Привет, "..имя.."!"
Печать приветствие
Печать "Счёт: "..5
```

Комментарии начинаются с `#` или `//` и идут до конца строки. Решётка и слэши внутри кавычек — часть текста, а не комментарий.

## Условия

`Если`, `Есле` и `Эсли` — одно и то же. После условия пишется слово `то`, блок закрывается словом `Конец`, посередине может быть `Иначе`. Веток `Иначе если ... то` может быть сколько угодно — выполняется первая подошедшая. Вложенные `Если` разрешены. Короткая однострочная форма тоже работает: `Если счёт > 3 то Печать счёт Конец`.

```text
Если счёт > 3 то
    Печать счёт
Иначе если счёт = 0 то
    Печать "ноль"
Иначе
    Печать "мало"
Конец
```

Сравнивать можно числа (`=`, `==`, `!=`, `<>`, `>`, `<`, `>=`, `<=`) и тексты (только `=` и `!=`). Условия можно соединять: `и`, `или`, `не`, скобки разрешены. Логические значения: `истина` / `ложь` (синонимы `да` / `нет`, `true` / `false`).

```text
Если счёт > 3 и имя != "гость" то
    Печать "прошёл"
Конец
```

Встроенный случайный диапазон: `Случайное.значение.от.1.до.10`.

## Циклы

```text
Пока счёт < 10 то
    Изменить счёт 1
Конец
```

`Пока условие то ... Конец` повторяет блок, пока условие верно. `Вечно ... Конец` — бесконечный цикл, выход командой `Прервать`. Вложенность любая.

## События

Скрипты стартуют по событиям. Слово `Конец` у событий допустимо, но не обязательно.

```text
При. запуске
    Печать "поехали"
Конец

При. нажатии
    Печать "кликнули"

При. нажатии клавиши.пробел
    Печать "прыг"

Каждые.5.секунд
    Печать "тик"

Каждый кадр
    Подвинуть. 1 0

Когда счёт > 10 то
    Печать "порог"
```

Доступные события: `При. запуске`, `При. нажатии` (клик по объекту), `При. отпускании`, `При. наведении`, `При. нажатии клавиши.КЛАВИША`, `Каждые.N.секунд` (секунда/секунды/секунд — любая форма), `Каждый кадр`, `Когда условие [то]` / `Как. только условие [то]`. Код вне событий выполняется при запуске как неявное событие.

Клавиши: `право`, `лево`, `верх`, `вниз`, `пробел`, `ввод` (Enter), `отмена` (Escape), `забой` (Backspace), буквы (кириллица и латиница) и цифры — самим символом: `клавиши.А`, `клавиши.5`.

## Свойства объекта

```text
Если Свойство.клавиша.пробел = истина то
    Подвинуть. 0 -5
Конец

Если Свойство.коснулся.монета = истина то
    Спрятать.монета
Конец
```

Доступные свойства: `Свойство.х`, `Свойство.у` (координаты), `Свойство.размер`, `Свойство.прозрачность`, `Свойство.нажат`, `Свойство.наведен`, `Свойство.коснулся.ИМЯ` (коснулся ли объекта с именем), `Свойство.клавиша.КЛАВИША` (зажата ли клавиша прямо сейчас).

## Команды объекта

```text
Показать
Спрятать
Спрятать.монета
Подвинуть. 10 -5
Задать размер. 150
Изменить прозрачность. 10
Задать яркость. 80
Задать изображение. герой.png
Изменить изображение. перед
```

`Показать` / `Спрятать` (`Скрыть` — синоним) — свой объект; с точкой и именем — чужой: `Показать.монета`. `Подвинуть. dx dy` — сдвиг по X и Y двумя целыми числами.

## Звук

```text
Зациклить звук.тема.mp3
Остановить звук.тема.mp3
Задать громкость. 50
Задать громкость.тема.mp3 50
```

## Изображения (анимация)

```text
Проиграть изображение.8
Проиграть изображение.монстр 8
Остановить изображение.
```

`Проиграть изображение.СКОРОСТЬ` — листание кадров своего объекта со скоростью кадров в секунду; с именем — чужого объекта.

## Сборка и запуск

Нужен компилятор C++17 или новее (консольный интерпретатор `main.cpp`).

```sh
g++ -std=c++17 -O2 -o iskra main.cpp
./iskra example.isk
```

В Windows откройте **Developer Command Prompt for VS 2026 Insiders** и выполните:

```powershell
cl /std:c++17 /O2 /EHsc /utf-8 main.cpp /Fe:iskra-runtime.exe
chcp 65001
iskra example.isk
```

Полноценный редактор и рантайм — проект `IskraStudio` (C#, .NET): открой `IskraStudio/IskraStudio.csproj` в Visual Studio и собери.

## Unit-тесты

Тесты логики интерпретатора находятся в `tests/interpreter_tests.cpp`. В Developer Command Prompt for Visual Studio из папки проекта запусти:

```powershell
cl /std:c++17 /EHsc /utf-8 tests\interpreter_tests.cpp /Fe:iskra-tests.exe
.\iskra-tests.exe
```
