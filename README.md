# Искра

Интерпретатор написан на C++. Исходники Искры используют расширение `.isk` и сохраняются в UTF-8 (с BOM или без него). Сейчас язык умеет хранить целые числа в переменных, менять их и печатать значения.

```text
Задать счёт = 5
Изменить счёт 1
Печать счёт
Изменить счёт -1
Печать счёт
```

`Задать` и `Присвоить` — синонимы: команда создаёт переменную или присваивает ей новое значение. `Изменить имя число` прибавляет число к переменной; отрицательное число уменьшает значение. Перед положительным числом можно поставить `+`. `Печать имя` выводит значение переменной. Регистр команд не важен, имена переменных чувствительны к регистру.

Переменные и команды разделяются пробелами. Значения пока только целые числа. Каждая команда пишется на отдельной строке.

## Сборка и запуск

Нужен компилятор C++17 или новее.

```sh
g++ -std=c++17 -O2 -o iskra main.cpp
./iskra example.isk
```

В Windows откройте **Developer Command Prompt for VS 2026 Insiders** и выполните:

```powershell
cl /std:c++17 /O2 /EHsc /utf-8 main.cpp /Fe:iskra-runtime.exe
chcp 65001
iskra example.isk
```
